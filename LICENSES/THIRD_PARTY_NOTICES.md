# Third-party notices (incomplete)

This register intentionally contains no inferred dependency notices. Gossip is
in Phase 0–1 and no dependency/provenance audit has been recorded.

Before adding third-party code, generated artifacts, WordPress source/theme/
plugin, assets, fixtures, container images, or Composer dependencies, record
origin, immutable version/hash, license/SPDX identifier, copyright/trademark
notice, distribution/source obligations, and review decision. See
[Licensing and provenance — PROPOSAL](../docs/licensing-proposal.md).

Potential WordPress compatibility work must account for WordPress's
GPL-2.0-or-later license and independently review every associated plugin,
theme, asset, and dependency. This file is not a license grant and does not
finalize Gossip's project license.
