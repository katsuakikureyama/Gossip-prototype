# Licensing and provenance — PROPOSAL

No final project license is selected here. The intended direction is Gossip
under a GPL-compatible license and GoHP under a permissive license, but both
remain provisional until dependency and provenance audits finish.

For every bundled, translated, tested, or redistributed upstream input, record:
origin URL and immutable version; source hash/acquisition date; declared license
and SPDX identifier; copyright/trademark notices and obligations; distribution
form (source/generated code/binary/assets/fixture/report); and review decision.

WordPress is GPL-2.0-or-later; each plugin/theme, Composer package, asset, and
fixture has its own license and needs separate evaluation. Do not copy unrelated
source without compatible licensing and retained notices. Do not imply WordPress
endorsement or use its trademarks as Gossip's brand.

- Preserve required license, attribution, source-offer, and NOTICE obligations.
- Generate SPDX/notices from an audited bill of materials, not guesses; see
  [third-party notices](../LICENSES/THIRD_PARTY_NOTICES.md).
- Do not assume WordPress.org API access permits redistribution or branding.
- Telemetry is opt-in and must not leak proprietary plugin source.

Pending owner/legal review: Gossip's final license/contribution policy, generated
artifact distribution, copyleft obligations of composed deployments, trademark/
API policy, dependency inventory, and notice generation.
